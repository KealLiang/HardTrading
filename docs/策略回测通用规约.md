# 策略回测通用规约

> 用途：任何策略回测开工前直接附上此文档，替代反复强调"别用未来数据""要可执行""结论别夸大"。
> 每条后面是**验收标准**（能检查的），不是建议。

---

## 0. 三条铁律

1. **回测里的每一笔交易，都必须是当时那个时点用当时可见的信息能做出的决策。**
2. **"测不出来"是合法结论，"接近显著"不是结论。**
3. **先证明规则优于随机，再谈规则为什么好。顺序颠倒的一切分析都是美化。**

---

## 1. 数据层

| 项 | 要求 |
|---|---|
| 复权 | 全周期统一口径。日线前复权 + 分钟线原价 = 除权日假暴跌，是最常见的假信号来源。分钟后数据必须按同一因子阶梯复权，并与日线在同一日做偏差检查（>1% 视为未对齐）。 |
| 标的刻度 | 拆股/份额折算会让相邻 bar 出现 −50%/−66% 跳变。入口做门禁：单根 OHLC 变动超过 ±30% 先怀疑刻度，不怀疑行情。 |
| 时间戳 | 明确每根 bar 的时间是**开始**还是**结束**。跨数据源、跨周期对齐**不要用时间字符串**，用「日期 + 日内序号」。 |
| 缺失与停牌 | 停牌 bar 缺失时不得用前值填充参与信号计算；持仓期横跨停牌要在报告里标注。 |
| 换源 | 允许换源，但换源后必须做「旧源 vs 新源」在同一口径下的结论对比表。结论翻转要查清是数据修好了还是样本变了。 |
| 数据落盘 | 原始数据不改写，复权/清洗产物另存目录，加载层留开关（`RAW_MIN=1` 之类）可退回。 |

**验收**：抽 3 个已知分红除权日，检查复权后无跳空；抽 1 个拆股标的，检查刻度连续。

---

## 2. 信号时点（防未来函数）

### 2.1 每个信号必须携带两个 bar 索引

- `readyK`：这个信号在**最早哪根 bar 收盘后才能被确认**
- `discT`：代码实际**发现**它的那根 bar
- `lag = discT − readyK`

只接受 `lag ≤ 1`。`lag > 1` 一律视为事后回填，剔除而不是修正——修正会掩盖"算法其实要看到未来才认得出"这个事实。

### 2.2 渐进切片验证（最硬的一条）

对每个 bar `t`：只喂 `[0..t]` 的数据重算信号，结果必须等于「全量算完再截取到 t」。
不一致 = 引擎内部用了全样本统计量（分位数、均值、极值、周期长度、聚类结果），该处即为未来函数。

### 2.3 常见隐患

- 指标预热不足（WARMUP 不够，前期信号是残缺状态的产物）
- 归一化/标准化用了全样本 mean/std
- 阈值来自全样本分位数（如"波动率前 20%"）
- 形态/结构识别里"事后才知道这笔没走完"（未完成结构被当成已完成）
- 用当日收盘价算信号、又用当日收盘价成交（见 §3）

**验收**：切片一致性 0 违规；lag 分布列表打印出来，`lag>1` 的笔数在报告里明写。

## 3. 执行层

| 项 | 默认规则 |
|---|---|
| 成交价 | **信号确认后的下一根 bar 开盘价**。禁止用信号 bar 的收盘价成交。 |
| 延迟 | 入场延迟固定 1 根；另跑 1/2/3/5 根做衰减曲线，衰减越陡说明越依赖瞬时价格。 |
| T+1 | 当日买当日不可卖。出场信号落在 T 日 → 最早 T+1 撮合。 |
| 涨跌停 | 涨停不可买、跌停不可卖，顺延到可成交的下一根。 |
| 无法合规出场 | 持有期未满或找不到合规 bar → **该笔作废**，不硬凑假出场。作废笔数要在报告里列出。 |
| 费用 | 双边手续费 + 滑点，基准与加倍两档做敏感性（结论只在低成本档成立 = 不可用）。 |
| 价格可用性 | 成交量不足以承载目标仓位时视为不可成交（大资金场景必做）。 |

**验收**：独立脚本复核「同日进出 = 0 笔」「入场价 = 次根开盘」「入场 bar 索引 = 信号 discT+1」。

## 4. 组合与资金

两种口径，**都要报**，不要混：

- **分账**：每类信号各占一套独立资金 → 分层指标真实，但资金占用会超过 100%，年化不可相加。
- **共享单仓**：一个账户、同时只持一仓 → 贴近实盘，但**先到的信号会吃掉后到的**。

共享单仓有三个必查副作用：

1. 分层表某格样本被别类吃掉 → 该格 n 极小，**不能用来评价该类信号**。
2. 存在**反向样本选择**：能成交的是"前一笔已结束之后才来的"信号，位置往往更差。此时成交样本的均值可能与该类信号真实表现相反。
3. 生成资金曲线时，**只有仓位不重叠的交易才允许连乘**。重叠还要串成一条曲线 → 年化与单笔均值必然自相矛盾（单笔为负、年化为正是典型症状，遇到就是 bug）。

必报指标：笔数、单笔均值/中位、胜率、盈亏比、持仓中位、赢家 vs 输家中位持仓、5% 分位、最大单笔亏损、年化、最大回撤、资金占用率。

**赢家持仓中位 < 输家持仓中位**是"截断亏损"在工作的指纹；倒挂说明止损位过松或出场滞后，先修规则再谈收益。

## 5. 对照组设计（决定结论能不能用）

### 5.1 四组 2×2 分解

| 组 | 入场 | 出场 |
|---|---|---|
| A | 策略信号 | 策略规则 |
| B | 策略信号 | 固定持有 N 根 |
| C | 随机入场 | 策略规则 |
| D | 随机入场 | 固定持有 N 根 |

- 出场贡献 = A − B（入场相同）
- 入场贡献 = A − C（出场相同）
- 基线 = D

**顺序**：先看 A 是否显著优于 D。不优于 D，后面所有分析都是在解释噪声。

### 5.2 持有期必须匹配（最容易犯的错）

A 与 B_N 比的是**持有期长度**，不是规则。低波动窗口里"早出场"必然赢、"长持有"必然输，这全是 beta。
公平比法：保持同一入场点，**持有期从 A 自身的持仓分布里随机抽**（每笔抽 100 次取均值），得到一个"持有期相同、出场时点随机"的基准 BM。另加一个 BMED（持有期固定为 A 的中位）。

A 相对 B_N 的优势，在 A 相对 BM 后归零 → 该规则的作用只是"挑持有期"，不是"挑时点"。这个区别必须写进结论。

### 5.3 配对检验

两组各自单仓，成交集合本来不同，直接比均值混进了样本差异。
只保留**两组都实际成交的同一入场点**，逐笔求差再平均。报告里必须标明哪些数字是配对的、哪些是非配对的，**同一结论内不得混用**。

### 5.4 随机组

多种子（≥50），报跨种子均值与离散度。随机组可以只存聚合值，但必须能证明"换种子结果不变"。

## 6. 统计口径

- **显著性**：|t| ≥ 2 且配对。达不到就写"测不出"。
- **多重比较**：几十个格子里冒出 1~2 个 |t|≈2 是正常的，单独拎出来当结论就是挑数据。事先声明主检验是哪一个。
- **独立试验数 ≠ 笔数**。必查收益集中度：
  - 前 5 笔占净收益比例（>100% 意味着去掉这 5 笔就是亏的）
  - 按入场月份/季度聚类，看信号是否挤在少数几段行情
  - 有效独立环境数（几个不重叠的行情区间）
  - t 值按笔数算的是**上界**，报告里要写明。更稳的做法：按时间聚类/bootstrap。
- **左尾**：5% 分位与最大单笔亏损，和对照组比。均值打平但左尾更深 = 用"赢面"换了"赢幅"，不算改进。
- **持仓分布**：均值之外必须报中位与赢/输家分列，长尾会把均值带偏。
- **年化**：写清口径——「每标的一份独立资金」还是「一个账户轮动」。两者不能混。样本首末日期要写实际值，不要写约数。

## 7. 独立复核（换人写一遍）

另写脚本，**不复用回测的算价函数**，从原始数据重算，逐项断言：

1. 入场价 = 报告里的价格（与原始数据对照）
2. 出场价、收益（含费用）= 明细行
3. T+1：同日进出 = 0
4. 入场 bar = 信号 discT + 1
5. 只使用 lag ≤ 1 的信号
6. 同一标的不存在持仓重叠（或重叠被显式允许）
7. **账目自洽等式**：信号总数 = 成交 + 被占用 + 作废 + 越界，逐项对齐

明细 CSV 必须存 **bar 索引**（不只是日期），否则低级别数据无法定位、复核会空跑。

**验收**：7 项全部为 0。报告写明复核脚本路径与最后运行时间。

## 8. 报告纪律

- **报告分两份**：结论版 ≤ 100 行（给人看、给 AI 读），完整版另存（逐格表、对照表，日常不看）。
- 报告由脚本生成，不手写。文字里的方向（"更差/更好"）必须由数据判断后生成，**不得硬编码**——一套文字套多周期/多标的，方向必然有反的。
- 结论段只引用配对后的数字；非配对数字单独标注。
- 样本量 < 30 的格子标 `n/a`，不参与排序、不参与结论。
- 样本内挑出的最优参数格子，明写"样本内最优，不作样本外预期"。
- 规则改动后必须重跑**全部**相关结果（含复核、配对、敏感性），不允许只重跑受影响的表。
- 每条局限写清"这会让结论偏高还是偏低"，最多 4 条，按重要性排。
- 不放过程叙述（"我先试了 A 又试了 B"）、不解释工具、不重复同一结论。

## 9. 失败模式速查

| 症状 | 大概率的病 |
|---|---|
| 单笔均值为负、年化为正 | 仓位重叠被串成一条曲线连乘 |
| 胜率 30% 但盈亏比 3+，均值仍不显著 | 收益靠少数极端赢家，先看集中度 |
| A 略优于 B，配对后消失 | 样本选择偏差（B 没成交而 A 成交的那批） |
| 结构出场对长持有全胜、对短持有打平 | 持有期长度差异，不是规则优势 |
| 低级别年化远高于高级别 | 持有期短 + 样本少 + 单一环境，三重偏差叠加 |
| 赢家持仓 < 输家持仓（倒挂） | 止损过松 / 出场滞后，先修规则 |
| 分层表某格 n 异常少 | 单仓被别类信号占用，反向选择 |
| 换数据源后结论翻转 | 先查复权与刻度，再查标的池变更 |
| 相邻 bar 出现 −50% | 拆股/份额折算未对齐 |

## 10. 交付清单

只要四样，其余都是过程物，不必交付：

| 项 | 内容 |
|---|---|
| 代码 | 扫描 / 回测 / 复核 / 报告 四个脚本；口径用环境变量切换，不改代码 |
| 数据 | 明细 CSV（含 bar 索引）+ 汇总 JSON；原始数据只读，清洗产物另存 |
| 报告 | **结论版 ≤ 100 行**：结论表、口径表、主表、检验表、局限 ≤ 4 条、复现命令 |
| 留档 | 完整版报告另一份（逐格全表、对照表），不进主交付、不给 AI 读 |
