    缠论实操速查 · 心法
    缠论是分类语言 + 风控语言，不是预测机器。
    它最大的作用：让你事先知道「错了怎么办」。
    规则的价值不在于每次都对，在于让你不用每次都重新决定。

    一、开仓前必须写下三句话

    写完才许下单，没写清就不许买。

    1. 我买的是哪个级别：30 分钟 / 日线 / 周线
    2. 我错了的标记：跌回中枢 ____ 元 / 跌破一买低点 ____ 元（必须是一个具体数字）
    3. 我打算怎么走：____ 级别出现 ____ 信号时出场

    第 2 条只用来开仓前算仓位（最坏亏多少 → 敢买多少），不是持有期的操作开关。单笔仓位 ≤ 总资金 10% —— 这是下面所有纪律能执行的前提。

    二、级别纪律（背下来）

    • 大级别定方向（能不能继续持有），小级别定时机（什么时候动手、减仓）
    • 买什么级别，就用什么级别的信号出，不许乱跳
    • 笔级别的卖点 =「要回调了」，不是「清仓」 → 它只配触发减 1/3
    • 三买/二买要下沉一个级别确认（日线三买用 30 分钟确认，这是正常的，不是信号缺失）
    • 提醒：插件默认笔中枢 ≈ 比本级别低一级，别拿它当「日线中枢」去读大趋势

    三、出场四层

    优先级触发条件动作
    1买点失效：跌破一买低点 / 跌回中枢无条件清仓。这是「买入理由没了」，不是止损
    2移动止盈被击破（前低 / 新中枢下沿）清仓。这是最常触发的正常出场
    3笔级别顶背驰出现只减 1/3，其余不动
    4操作级别出现背驰一卖分批减仓兑现（别等二卖，二卖要多回吐一段）

    移动止盈是主力手段：每个次级别回调低点就是跟踪位；形成新中枢就用新中枢下沿。
    「跌回中枢」是兜底线 —— 轮到它触发，说明前面几层都失效了，那是极端情况，不是日常。

    四、特殊情况

    • 横着不动：时间到了就走。买入后超过该级别中枢平均时长 ×1.5 还没启动 → 退。理由是机会成本，不是亏钱。
    • 出利空（加息 / 行业 / 大盘）：浮盈 → 收紧止盈；刚买就浮亏 → 直接走；横盘中 → 减半。
    • 想扛一下：先问「我的失效位到了吗」。没到 → 规则没让你走，别动。到了 → 别找理由。
    • 踏空了 / 卖飞了：不许改规则。单次结果是噪音，改规则才是真亏。

    五、四条禁令

    1. 不许用低于买入级别的信号清仓
    2. 不许开仓后临时放宽失效位
    3. 不许「再看看」—— 到了就执行，犹豫本身就是成本
    4. 不许用一个样本（某只深 V、某次踏空）推翻规则
    你不需要每次都对，你需要在每次都做同一个决定。
