# 止损缓冲系数 k：取多少性价比最高

> 43 只个股日线 5857 笔｜43 只 ETF 日线 1986 笔｜26 只 ETF 30m 1042 笔
> 持有 20 个交易日（30m 为 160 根）｜费 0.1% 双边｜止损价 = 失效位 − k×ATR20

## 结论

**1. k 不是减少错误止损的工具。** 个股日线六档 k，砍错率 52.8%~57.0%、真救率 43.0%~46.9%，几乎不动；30m 同样，43~48% / 52~58%。止损打得准不准由失效位本身决定，加多少缓冲都改不了这个比例。ETF 日线是唯一例外，而且方向更坏：k 越大砍错越多（50.1% → 65.5%）。

**2. k 改的是打多少枪。** 个股日线 k 从 0.5 到 2：止损率 37.5% → 17.1%，假止损从占总笔 17.3% 降到 4.8%（少打 72%），代价是单笔亏损超 20% 的概率从 0.63% 升到 1.62%。

**3. 性价比拐点是「止损距离 7%」，现行 k=0.5 正好落在那里。** 个股日线固定距离扫描：止损从 3% 放到 7%，每放宽 1 个百分点换 +0.116pp~+0.150pp；从 7% 再往宽放，每 1 个百分点只剩 +0.029pp（1/5）。**过了 7%，加宽就只是白担风险。** 现行 k=0.5 的止损距离中位 7.06%（均值 8.92%），跨在拐点上。

**4. 唯一值得改的是三买：k=0.5 → 1。** 三买单笔 +1.65pp → +1.79pp，配对差 +0.14pp、t=2.39；2020 年前（+2.02pp→+2.21pp）、2020 年后（+0.99pp→+1.03pp）两段同向。一买、二买维持 0.5（一买 k=2 的 +0.17pp 只在 2020 年前成立，2020 年后反向，不可信）。

**5. 30m 的 k=0.5 只有 2.00% 的距离，止损率 73.9%。** 30m 的失效位天然贴得近。如果持仓是一个月，用 30m 失效位守仓位，止损会变成主要出场方式（74% 的笔被打），这不是调 k 能解决的，是周期错配。

- 个股日线：拐点 **−7%**，过了这里边际收益掉到 +0.029pp（前面的 1/5）。

## 5 换周期时 k 不能照搬

| 周期 | ATR20 占价（均值） | k=0.5 的止损距离（中位） | k=0.5 的止损率 |
|---|---|---|---|
| 日线 | 3.48% | 7.06% | 37.5% |
| 30m | 0.88% | 2.00% | 73.9% |

同一个 k=0.5，日线是 7.06%、30m 是 2.00%，差 3.5 倍。**k 是 ATR 的倍数，不是距离。**

按「失效位距离 + k×ATR20」拆开：日线 5.32% + 0.5×3.48%，30m 1.56% + 0.5×0.88%。要让 30m 的止损也有日线那么宽（7.06%），k 得放到 **6.2**。
但 30m 上根本走不到 6.2：k 从 0.5 加到 3（距离 4.04%），收益已经从 −0.14pp 掉到 −0.69pp（差 −0.55pp）。**把 30m 的止损往宽拉是净损失**——两边的失效位本来就不是同一个尺。

30m 的 k 跟持有期强相关：持仓 5 天（N=40）时 k=1.25 最优（+0.20pp），持仓 20 天（N=160）时 k=0.5~1 最优（-0.14 ~ -0.12pp）。**周期越短，k 越要往上抬。**

## 6 怎么调

| 项 | 建议 | 依据 |
|---|---|---|
| 全局 k | 保持 0.5 | 中位距离 7.06%，正好在性价比拐点上 |
| 三买 | 0.5 → 1 | +0.14pp，t=2.39，两段同向 |
| 一买 / 二买 | 保持 0.5 | 放大无显著收益，2020 年后反向 |
| 30m 跟踪 | 不要用它守一个月的仓位 | 中位距离 2.00%，止损率 74% |
| 30m 自己的仓位 | 持仓 5 天用 k=1.25，持仓 20 天用 k=0.5~1 | N=40 时 k=1.25 给 +0.20pp（k=0.5 是 +0.10pp）；N=160 时 k=1 给 -0.12pp（k=0.5 是 -0.14pp） |

## 附录 口径

- 样本：信号 lag=1（发现次日开盘入场）；个股再剔除一字涨停与停牌复牌日（信号与基线同步剔）。
- 止损：入场后第 1 根起，最低价触及止损价即成交；跳空低开按开盘价成交，不偷价。
- 「净节省/次」= mean(不砍而持满 N 根的收益 − 止损收益)，只在被止损的笔上算。正值 = 止损在赔钱，负值 = 止损在赚钱。
- 独立校验：抽 300 笔用 Python 直读 CSV 重算 ATR20、k=0.5 出场、固定 −7% 出场，三项逐位一致（0 / 0 / 0）。
- 复现：`STOCKS=1 node bt_k.js`（个股日线）、`node bt_k.js`（ETF 日线）、`TF=30 N=160 node bt_k.js`（30m），再 `node report_k.js` 生成本报告。
- 原始表：`out/bt_k_stock.txt` / `out/bt_k.txt` / `out/bt_k_30.txt`。
