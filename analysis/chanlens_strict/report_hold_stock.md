# 日线买点（个股）：信号到底有没有超额收益

> 43 只个股｜2005-01-04 ~ 2026-10-30｜一买 2247~2290、二买 1274~1294、三买 2322~2340 个信号
> 买点收盘确认 → 次日开盘买 → 持有 x 个交易日 → 开盘卖，扣双边 0.1%｜生成 2026-11-01 20:39

## 结论

**一买：全段有超额；二买：部分成立；三买：全段负超额**

| 类型 | 信号数 | 进场位置 | 判定 |
|---|---|---|---|
| 一买 | 2247~2290 | 250 日分位 34.07%（偏低） | **全段有超额**（6 个持有期全部显著为正） |
| 二买 | 1274~1294 | 250 日分位 42.67%（中间） | **部分成立**（4/6 个持有期显著为正） |
| 三买 | 2322~2340 | 250 日分位 78.86%（偏高） | **全段负超额**（6 个持有期全部显著为负） |

**超额**（单位 pp = 百分点）＝ 这笔实际赚的钱 −「同一只标的、同一个季度、价格分位 ±0.15 的普通交易日」赚的钱。把「那阵子大盘在涨」和「买得便宜」都扣掉，剩下的才算买点自己的本事。

> 三买拿 20 天单笔赚 1.83%，但同期同价位的普通交易日能赚 2.92%。**它赚的是行情，不是买点。**

## 1 超额收益（单笔 → 扣掉基准）

| 持有 | 一买 | 二买 | 三买 |
|---|---|---|---|
| 3 天 | 0.26% → **+0.51pp** | 0.23% → **+0.27pp** | 0.22% → **-0.30pp** |
| 5 天 | 0.37% → **+0.60pp** | 0.24% → +0.23pp | 0.23% → **-0.60pp** |

| 10 天 | 0.63% → **+0.80pp** | 0.72% → **+0.51pp** | 0.75% → **-0.84pp** |

左边是这笔实际到手（单笔平均，已扣 0.1% 费用），右边是扣掉「同期同价位随便买」之后剩下的。**粗体 = 统计上站得住（t ≥ 2）**，完整 t 值在附录 A。
一买 6/6 个显著为正；二买 4/6 个显著为正；三买 0/6 个显著为正、6 个显著为负。

## 2 基准：同期同价位随便买能赚多少

| 持有 | 一买 | 二买 | 三买 |
|---|---|---|---|
| 3 天 | -0.25% | -0.04% | 0.52% |
| 5 天 | -0.23% | 0.02% | 0.83% |
| 7 天 | -0.21% | 0.09% | 1.14% |
| 10 天 | -0.17% | 0.21% | 1.59% |
| 20 天 | 0.07% | 0.77% | 2.92% |
| 60 天 | 2.41% | 3.90% | 6.82% |

基准 = 同一只标的、同一个季度、过去 250 日价格分位 ±0.15 的所有交易日，各买一次拿同样的 x 天，取平均。
**一买的基准是负的**：在「跌了很久、位置很低」的时点随便买，3~20 天平均亏 -0.25% ~ 0.07%（60 天转正 2.41%，因为这段时间本身有反弹），而一买还能赚 0.26% ~ 1.60%。这才叫超额。
**三买反过来**：那个位置本来就容易涨（0.52% ~ 6.82%），三买只赚到 0.22% ~ 4.64%，比随便买还少。

一买 3 天到手只有 0.26%：毛收益约 0.36%，0.1% 的费用占掉 28%。拿 20 天是 1.60%，费用只占 6%。**短线被费率吃掉利润。**

## 3 怎么用

1. **做一买，拿 20 天。** 超额最高（+1.53pp）、最稳（t=8.75）、单笔 1.60%。
2. **别做 3 天。** 超额有，但单笔 0.26%，0.1% 的费用占掉 28%。
3. **二买只能当辅助。** 4/6 个持有期显著，超额大约是一买的一半；而且只在同价位对照下成立，对当月平均行情没有优势。
4. **三买不当入场信号。** 它的用处只在趋势确认（说明中枢被突破且回踩成功），收益上体现不出来。

## 4 这个结论有多可信

| 质疑 | 检验结果 |
|---|---|
| 是不是某一只的运气 | 一买在 43 只有效标的中，74.42%~97.67% 为正 |
| 是不是被重叠信号撑大了 t | 每只标的先算一个均值再检验：x=20 一买 +1.52pp（t=9.08），95.35% 标的为正 |
| 是不是只靠某一段行情 | 2020 年前 1240 笔、+0.58pp（t=3.60）；2020 年后 1035 笔、+0.61pp（t=4.12） |
| 有没有偷看未来 | 确认日收盘后才知道信号，次日开盘才买；独立脚本重算原始 CSV：入场违规 0、价格不一致 0 |

- **两段都成立**：2020 年前 +0.58pp（t=3.60）、2020 年后 +0.61pp（t=4.12），不是在某一波行情里凑出来的。
- **持仓重叠**：同标的连续信号叠加率 x=3 9.85%、x=5 18.36%、x=7 25.86%、x=10 35.28%、x=20 52.82%、x=60 85.64%。重叠会让逐笔 t 偏大，所以以附录 B 的跨标的 t 为准。
- **无单仓约束**：假设每个信号都有钱买。实际多个买点同时出现只能选一个，且可能没钱。
- **成交价与滑点**：一律按开盘价成交、费用双边 0.1%（佣金万 0.5~2 + 卖出印花税 0.05%，合计约 0.06~0.1%，与假设接近）。滑点没算——大盘股开盘价差 0.02~0.05%，情绪股可能 0.2~0.5%，会吃掉一部分超额。
- **x=20 是从这批数据里挑出来的最优**，不是在实盘前就定好的。好在一买 3~60 天全部显著为正，换个持有期不至于翻盘。
- **入场可行性**：一字涨停（开=高=低且涨 >4.5%）的日子买不进，已从信号与基线池同时剔除，合计 186 个交易日；长期停牌（与前一交易日间隔 >15 自然日）剔除 78 个。

## 附录 D 复现、可执行性、复核

**信号不是事后回填的**：`scan.js` 对每只标的逐根回放——第 t 根收盘时只用 `ks.slice(0, t+1)` 重跑一遍引擎，买点是那一刻引擎真的报出来的，记下首次发现时间 discT，买入 = discT + 1 的开盘价。价格分位也只用过去 250 根。

```bash
cd D:/Trading/analysis/chanlens_strict
STOCKS=1 TF=daily node scan.js   # → tmp/pack_daily_stock.json
STOCKS=1 node bt_hold.js          # → report_hold_stock.md + out/bt_hold_stock.json
STOCKS=1 node verify_hold.js      # 独立复核
STOCKS=1 node stability.js        # 信号发现后会不会消失
```

`verify_hold.js` 直接读原始 CSV 重算，不复用 bt_hold.js 的任何算价函数：

| 检查项 | 结果 |
|---|---|
| 入场日 = 确认日 + 1（逐笔对 CSV 相邻行） | 违规 0 |
| 卖出日 = 入场日 + x，开盘价逐笔一致 | 不一致 0 |
| 只用 lag = 1 的信号 | 剔除 464（脚本记 464） |
| 确认日之后没有下一根 K 线（不成交） | 剔除 0 笔 |
| 18 个格子（6 个 x × 3 类）的 n / 均值 / 胜率逐位比对 | 全部一致 |
| 「同季同价位」基线用 CSV 独立重算 | 差异 0.001pp（2277 笔） |

**买点会不会隔天消失**（`stability.js`：发现后再放几根 K 线重算，看同一个买点还在不在）：

| 同一个买点仍在 | 100.00% | 96.82% | 90.40% | 76.30% |

买入那一刻（discT+1）信号 100% 在；越往后越多买点被合并进新的笔、从视图里消失，6 根后剩 76.30%。**这不影响下单时点，但意味着事后复盘看到的图与当时不完全一样。**

## 附录 E 三买亏在哪一档

按「入场价距中枢上沿」切开（x=20 天，其余口径同正文）。中枢上沿 = 那个中枢的 ZG；回踩不落回 ZG 才算三买，所以这个距离约等于「突破那一段已经走掉多少」：

| 距中枢上沿 | n | 单笔 | vs 同价位（t） |
|---|---|---|---|
| ≤5% | 629 | 1.68% | -0.28pp |
| 5~10% | 790 | 2.16% | -0.20pp |
| 10~20% | 607 | 1.78% | **-1.70pp** |
| >20% | 291 | 1.37% | **-3.95pp** |

**61.24% 的三买入场价在中枢上沿 10% 以内**，这一档 -0.24pp（t=-1.15），等于打平；另外 38.76% 落在 10% 以外，-2.43pp（t=-6.29）——**亏损几乎全在「涨完了才回踩」这一档**。

用法：给三买加一条「入场价 ≤ 中枢上沿 × 1.10」的过滤。这条阈值是回头切数据切出来的、不是先验，实盘要按当时能看到的 ZG 现算，并接受它可能只是这批样本的巧合。
