# 阿尔法存在吗：能不能被套利掉

> 43 只个股（2005-01 ~ 2026-10）+ 43 只 ETF 对照｜持有 20 日｜扣双边费 0.1%
> 超额 = 单笔收益 − 同标的、同季度、同价位（|Δ分位|≤0.15）的对照日均值

## 结论

1. **主线过滤增加的是 beta，不是 alpha。** 同期、同价位、同动量三个口子都锁住以后，行业强度对超额的增量归零。这一项到此为止。

2. **alpha 存在，而且二十年没被抹平。** 一买 20 日超额 +1.57pp（t=8.78）；把「过去 20 日跌幅」这个已知因子也锁死，仍有 +1.18pp（t=7.02）——只有 25% 来自「跌多了」。ETF 池同向（+1.36 → +1.30）。

3. **但一买的大部分 alpha 属于「短期反转」这个公开因子。** 不用缠论，只在个股自身 20 日动量分位 ≤10% 的日子买、持 20 天：+1.13pp 超额（t=18.22）。一买比它多约 0.4pp。**这是缠论自己的增量，也是这套系统真正的 alpha。**

4. **衰减测不出来。** 一买超额斜率为 −0.77pp/10 年（t=−1.47），纯反转 −0.24pp/10 年（t=−0.47），都不显著。三买反向：+1.52pp/10 年（t=3.85），从 −2.05pp 收窄到 −0.34pp。

5. **它不是「免费的钱」，是风险补偿。** 超额与同期市场环境相关系数仅 +0.16，市场差的那半段 +1.37pp、市场好的那半段 +2.14pp——两种环境都为正，不是熊市对冲，是「持续承担买在下跌中」的风险换来的一点补偿。

6. **「主动基金跑不赢指数」不等于「没有 alpha」。** 那是算术：全体主动管理者的超额之和恒为零，扣掉费用后必然为负。它约束的是平均水平，不是每个个体。

## 复现

```
STOCKS=1 node bt_decay.js   # 逐年衰减 + 市场环境相关性
STOCKS=1 node bt_alpha.js   # 因子剥离 + 纯反转/纯动量对照
node bt_decay.js && node bt_alpha.js   # ETF 池
```
原始表落 `out/bt_decay*.txt`、`out/bt_alpha*.txt`。

## 已知限制

- 纯反转对照用的是「同标的自身动量分位」，不是全市场截面；43 只票的截面太小，做不了标准的分组回测。
- 滑点未计。一买 20 日毛超额 +1.57pp，扣 0.2% 滑点后约 +1.37pp；3 日那档扣完只剩零头。
- 容量未测。反转因子在资金规模上有限制，这是它没被抹平的原因之一，也是它不能放大的原因。
