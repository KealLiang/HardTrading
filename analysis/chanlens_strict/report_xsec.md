# A 股全市场量价因子检验（论文口径）

> **结论：论文那个「价量趋势因子」在我这里复现失败。A 股真正稳的只有「小盘/低流动性」，但大票上失效。大票上能用的只有「低换手 + 不追涨」，本质是同一件事。**
>
> 样本：全 A 股 5332 只，2013-01 ~ 2026-09，165 个月，每月横截面约 2351 只。
> 口径：月末信号 → 持 20 个交易日 → 扣 0.1% 双边费。收益用涨跌幅累乘（等价前复权）。
> 脚本：`bt_xsec_build.js`（面板）+ `bt_xsec_stat.js`（统计）。

## 二、三个关键发现

### 1. 论文的价量趋势因子：复现失败，且对定义极度敏感

我用两种常见构造方式实现：

- **A（均线偏离差）**：`(短期均线偏离 3/5/20 日平均) − (长期 60/200 日平均)`，t = +1.67
- **B（VWAP 比）**：`短期成交量加权均价 / 长期成交量加权均价 − 1`，t = −1.80

**两者相关系数 −0.90**，几乎互为反面，方向相反。

这说明该指标没有稳健定义——换个构造方式，符号就翻过来。**在这个状态下无法作为实盘依据。**

与 Li, Liu, Liu & Wei (2024) 的结论一致：他们复现 469 个 A 股异象，83.37% 在正确断点和市值加权后不显著。

### 2. 唯一通过 t>3 的是「小盘 + 低流动性」，但大票上归零

Amihud 非流动性 t=5.36、成交额 t=−4.76，两口径（等权/加权）都过线，分 14 个年份几乎年年为正。看起来极强。

但把它放到大票子样本（成交额前 30%）：**Amihud 从 t=5.36 掉到 t=1.04，量比从 −2.98 掉到 −0.91。**

这两个因子和「成交额」的相关系数是 −0.67，本质是同一个东西。**它赚的是微盘股的钱，而微盘股买不进、容量不够**（Li et al. 2024 批评的正是这一点）。

### 3. 大票上真正有效的是「低换手」，而且比全池更强

20 日均换手：全池 t=−1.53（无效），**大票 t=−3.00（有效）**。异常换手 t=−2.75 同向。

原因：小盘股换手率天然高且噪音大；大票换手率分化度小，信号更干净。这个方向和 Liu-Stambaugh-Yuan (2019) 的 PMO 因子（异常换手衡量情绪）一致。

## 三、回答「脱离缠论只测量价，能符合论文吗」

**不能。**

| 论文结论 | 本项目实测 | 是否吻合 |
|---|---|---|
| 价量趋势因子是 A 股最强因子 | 两种定义 t=1.67 / −1.80，且互相矛盾 | ✗ 不吻合 |
| 流动性是最重要预测变量（Leippold 2022） | 是，但纯粹是小盘效应，大票上归零 | △ 部分吻合 |
| 市值加权/正确断点后 83% 异象消失（Li 2024） | 8 个量价因子里只有 2 个过 t>3 | ✓ 吻合 |
| A 股动量弱（相对美股） | t=0.71，完全无效 | ✓ 吻合 |
| 低换手/低情绪溢价（LSY 2019） | 大票 t=−3.00，有效 | ✓ 吻合 |

**四条吻合、一条不吻合。** 不吻合的那条，恰好是「量价趋势」——也就是论文宣传得最响的那个。

## 四、对你实盘的意义

大票上能用的只有三条，而且是同一件事的不同说法：

1. **换手率低**（20 日均换手在全市场大票里偏低）→ t=−3.00
2. **异常换手低**（近 20 日换手 / 250 日均换手 < 1）→ t=−2.75
3. **过去 1 月没怎么涨**（短期反转）→ t=−2.19

三条都在说：**别买正在被热炒的票。** 这跟缠论一买（跌够了、情绪冷）天然吻合，也跟三买（追启动）天然冲突。

**这正好解释了之前三买为什么差**——三买赚的是动量，而动量在 A 股是负的（t=0.71），换手高、涨得多，三条全踩。

## 五、局限

1. **无市值数据**，用成交额代理规模和流动性，会混入「关注度」效应。
2. **未剔除涨跌停不能买入的样本**，会略微高估因子收益（尤其反转因子）。
3. **ST 状态是当前状态反推**，历史 ST 未还原。
4. **等权口径天然偏微盘**，已用「剔除最小 30%」和「大票域」两重对照缓解。
5. **未计冲击成本**：微盘因子年化 25pp 在实盘中不可实现。
6. 价量趋势因子的论文原式未获得原文，A/B 两种构造均为近似，**不排除实现偏差**——但这恰恰说明该因子不稳健。
